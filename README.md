# フリマ売上ランキング

4人のフリマの売上を記録して、合計額で順位をつけるページです。記録はGoogleスプレッドシートに保存されます。

- `index.html`：ページ本体（GitHub Pagesで公開）
- `apps-script/Code.gs`：スプレッドシートに貼るプログラム

## スプレッドシートの準備

1. Googleスプレッドシートを新しく作る
2. 「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `apps-script/Code.gs` の中身を貼って保存する
3. 「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、アクセスを許可する（「安全ではないページ」と出たら「詳細」→「（プロジェクト名）に移動」）
5. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）を `index.html` の `API_URL` に入れる

`Code.gs` を直したときは「デプロイを管理」→ 編集（鉛筆）→ バージョン「新バージョン」で更新すると、URLは変わりません。
